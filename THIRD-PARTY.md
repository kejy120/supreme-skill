# Skills de terceros (NO incluidas en este repo)

`supreme` enruta y mide sobre las skills que tengas instaladas, pero este repo **no redistribuye** skills ajenas
(cada una tiene su licencia y su repo). Si las quieres, instálalas tú desde su origen, en `~/.agents/skills/`
(global) o `<proyecto>/.agents/skills/` (solo ese proyecto). El formato `SKILL.md` es el mismo.

| Repo | Qué aporta |
|---|---|
| `dietrichgebert/ponytail` | Soluciones mínimas, revisión contra sobreingeniería |
| `juliusbrussee/caveman` | Modo de salida comprimida y skills de construcción acotada |
| `worldflowai/everything-claude-code` | Patrones backend/frontend, TDD, bucle de verificación |
| `mattpocock/skills` | Skills de ingeniería: TDD, diagnóstico, refactor, revisión |
| `obra/superpowers` | Planes, depuración sistemática, worktrees, verificación |
| `leonxlnx/taste-skill` | Dirección de diseño frontend |
| `bergside/awesome-design-skills` | ~67 design systems como skills (úsalos con `bin/ds.mjs`, a nivel de proyecto) |
| `miqdadbadjuber/anti-slop` | Reglas anti-relleno para UI, copy y código |
| `Graphify-Labs/graphify` | Grafo de conocimiento de un repo |

Antes de instalar una skill de terceros: léela entera (es texto que tu agente obedecerá) y, si puedes, pásale un escáner
de skills. `supreme` no instala nada por su cuenta: detecta el hueco, propone el repo y espera tu sí.
